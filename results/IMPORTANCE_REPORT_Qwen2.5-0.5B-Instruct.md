## How to read this

- If EMA recall is not clearly above recency recall, attention-based ranking cannot be expected to beat the recency heuristic on quality: it is not keeping more of the attention the model will use.
- The gap between the oracle and both policies is the headroom any importance predictor could still gain.
- Attention mass is a proxy for a token's influence; it ignores the size of value vectors.
